# System Overview

Singularity Operator is an experimental autonomous knowledge, validation, and orchestration platform.

Core focus areas:

- Memory systems (EverythingDB)
- Agent collaboration and free-AI rotation
- Knowledge validation and provenance
- Architecture evolution via SelfImprover + Orchestrator
- Cross-system orchestration (GitHubSeamless, currency signals, fleet sync)

The project prioritizes practical autonomous system development through iterative evolution rather than speculative end-state intelligence claims.

## Primary Components

- **EverythingDB** — structured knowledge capture and sequence completion
- **SelfImprover** — free-AI primary continuous improvement loop
- **Orchestrator** — task scheduling, continuous_roi_rank, currency_signal
- **FreeAIClient** — zero-cost provider rotation and failover
- **GitHubSeamless** — AGA metrics, currency signals, fleet actions
- Supporting engines: Chaos, Serendipity, Browser automation, Userscript generation

## Design Principles

1. Traceability and verifiability over opaque autonomy
2. Zero-cost / free-tier first operation
3. Continuous improvement with measurable ROI signals
4. Clear module contracts and documented boundaries
5. Archive obsolete speculative material; keep active docs current
